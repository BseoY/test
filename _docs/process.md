# Process

## 1. Tasks are GitHub issues, worked one at a time
Each task in `tasks.md` is tracked as a GitHub issue. Work on a single issue at a time and finish it before starting the next.

## 2. Read the acceptance criteria before starting and before closing
Read the issue's acceptance criteria before you start work. Read them again before closing the issue, and confirm each one is met.

## 3. Commit regularly
Make small, frequent commits with clear messages rather than one large commit at the end.
